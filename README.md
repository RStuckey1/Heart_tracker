## Description
# Your Health, In One Place
### This App is the best way to track your heart health. Made for people with Congestiive Heart Failure, this is the place to keep all your information to share with your Doctor.
**Designed to make everyday tracking easier—not replace medical advice****

## Installation

1. 
Clone the repository: https://github.com/RStuckey1/Heart_tracker.git

2.
In the command prompt, run 
```
npm install
```
3. 
```
npm run build
```
4.
```
npm run start:dev
```

## Features
- Secure individual account creation
- Health readings for Blood Pressure, Pulse, and Weight
- Journal entries for workouts, meals, symptoms, and notes
- Sorting and graphing of entries
